# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **10.2** (2026-11-06)

- Projetista · prancha técnica do projeto importado em desenho de linhas, sem as linhas escondidas: vistas frontal, lateral e superior com as cotas gerais em mm, mais a isométrica. A lista de peças vem numerada e agrupada por medida, com os totais. Na vista explodida, a isométrica grande leva o número de cada peça.
- Projetista · Pintar funciona no projeto importado: pinta tubos, chapas, perfis ou barras, ou só as peças marcadas, com tom, RAL e acabamento. Antes o projeto sumia da tela.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
