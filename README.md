# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **10.61** (2026-11-06)

- Gerador: DXF com linha de dobra inclinada (na camada DOBRA, ex.: degrau em trapézio) agora entra com a dobra, com o sentido e o ângulo escritos ao lado da linha.
- Projetista: botão "+ Tubo" põe um tubo em pé (coluna ou tubo central de escada caracol). Tubo mandado do Gerador também chega em pé.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
