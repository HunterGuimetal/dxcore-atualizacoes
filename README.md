# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.37** (2026-10-07)

- Gerador/Editor de peças: nova ferramenta Selecionar (tecla S) — clique ou arraste uma janela para escolher várias linhas, arcos, círculos e furos de uma vez (janela para a direita pega o que está dentro; para a esquerda, o que encosta).
- Com a seleção: Mover, Copiar (várias cópias seguidas), Girar, Espelhar (podendo manter o original) e Apagar (ou Delete). Cada ação é um passo do Ctrl+Z.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
