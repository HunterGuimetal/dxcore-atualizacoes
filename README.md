# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **10.59** (2026-11-06)

- Orçamento: em cada material e espessura, botão "Chapas de tamanhos diferentes…". Digite as chapas na ordem do corte (ex.: 1500 × 1500 e depois 1500 × 1000, quando a mesa é dividida com outra espessura na outra metade). O encaixe enche a 1ª chapa, passa para a 2ª e assim por diante (a última repete se ainda sobrar peça), e o peso e o material saem pelo tamanho de cada chapa.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
