# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.41** (2026-11-03)

- Parâmetros e preços · novo campo Margem da chapa (padrão 10 mm em cada lado), que antes era fixo.
- Limpar e Dividir para caber na mesa passam a usar a mesma área útil da Calculadora (mesa menos a margem). Antes o Limpar aceitava a peça na chapa cheia e a Calculadora recusava. Quando é a largura que não cabe, o aviso explica que dividir não resolve.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
