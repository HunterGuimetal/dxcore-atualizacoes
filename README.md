# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.33** (2026-10-29)

- Proposta em PDF · segure Ctrl e clique nos orçamentos para selecionar (no celular, toque e segure; Shift + clique marca o intervalo). Com orçamentos selecionados aparece a barra para Selecionar todos, Cancelar ou Excluir (com confirmação). Delete exclui e Esc cancela.
- Visual · efeito vidro nos temas claro e escuro: o fundo ganhou luzes suaves paradas e as caixas, listas, cartões, janelas e o cabeçalho ficaram translúcidos com desfoque.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
