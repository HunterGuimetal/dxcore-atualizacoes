# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.38** (2026-10-07)

- Mais rápido com a pasta de dados da rede: as telas não releem mais todos os arquivos a cada clique. A mesma lista pedida por várias partes da tela é lida uma vez só e fica guardada por alguns segundos (o que este computador grava aparece na hora; o que outro PC grava aparece em até 2,5 s). Num teste com 600 OS, o Painel do dia passou de 1.950 arquivos lidos para nenhum.
- Calculadora: em pedido grande, o total é recalculado quando você para de digitar, sem travar a digitação. Uma quantidade gigante digitada errado não trava mais o programa: o encaixe é feito num bloco e repetido, com aviso para conferir a quantidade.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
