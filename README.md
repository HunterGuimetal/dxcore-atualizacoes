# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.58** (2026-11-06)

- Projetista · dimensiona sozinho: “faz o tampo aguentar 250 kg” testa reforço e chapas mais grossas numa cópia do projeto e mostra as opções que passam, da mais barata, com botão para aplicar.
- Projetista · “deixa mais barato”: testa cada economia (tubo menor, parede mais fina, sem espelho, sem reforço) e só recomenda o que não deixa nada fraco, com quanto economiza.
- Projetista · “revisa o projeto”: nota de 0 a 10 com o que está bom e o que olhar (carga, mesa de corte 3000×1500, barra de 6 m, ergonomia, inox para alimento, porta, peso para carregar).
- Projetista · “quantas barras?” (encaixe nas barras de 6 m com sobra e aproveitamento, chapas e comprados) e “quanto tempo leva?” (horas por etapa: corte, laser, dobra, montagem, solda, acabamento).
- Projetista · opções A/B: “salva como opção A”, “compara as opções” (medidas, peso, peças, carga e custo lado a lado) e “volta para a opção A”.
- Projetista · padrões da casa: “sempre usar tubo 30x30x1,2” entra em todo projeto novo; pedidos pela necessidade: “bancada para 3 pessoas”, “mesa para 8 pessoas”.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
