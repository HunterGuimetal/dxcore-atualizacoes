# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.41** (2026-10-08)

- Aguenta milhares de clientes: a lista inteira agora é lida de uma vez só (um arquivo-resumo na pasta de dados) e depois cada computador relê apenas o que outro computador mudou. Antes, com 7 mil clientes, o DXCORE relia 7 mil arquivos a cada poucos segundos e travava. Na primeira vez que abrir depois da atualização, um computador organiza a lista (pode levar um pouco); depois fica rápido em todos.
- Clientes: a tela mostra os 150 primeiros e a busca acha qualquer um pelo nome, nome fantasia ou CNPJ. Importar planilha grava várias fichas ao mesmo tempo e mostra o andamento, sem travar a tela.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
