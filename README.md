# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.11** (2026-10-05)

- Orçamento: nova opção "Material fornecido pelo cliente (parte)". Digite os kg que o cliente fornece e o DXCORE cobra só o material que falta para completar o pedido.
- O DXCORE passa a abrir pelo endereço da internet (sem internet, abre a cópia do computador). Assim dá para instalar como aplicativo e o navegador para de pedir a autorização da pasta toda vez.
- Na primeira vez em cada computador: escolha a pasta de dados da rede (DXCORE-dados) e, quando pedir, "Permitir em todas as visitas" ou instale pelo botão "Instalar o DXCORE neste computador".

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
