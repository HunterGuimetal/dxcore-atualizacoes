# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.42** (2026-10-08)

- Tela inicial na hora: trocar de setor não espera mais a pasta de dados. A tela aparece com os últimos números e eles se atualizam sozinhos quando a pasta responde. Clicar rápido em vários setores também não embaralha mais a tela.
- Menos pedidos à pasta da rede: os computadores conferem as mudanças juntos (uma consulta só para todas as listas) e, depois de uma importação grande, não releem mais a importação inteira a cada poucos segundos.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
