# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.37** (2026-11-03)

- Limpar · PDF de projeto (planta baixa, vistas do móvel, legenda de acabamentos, como os de arquitetura do ArchiCAD) agora é reconhecido e recusado com explicação, em vez de virar peça. Antes o Limpar tirava "peças" da legenda e das etiquetas. Para esses casos: peça ao cliente o DXF/DWG das peças ou o STEP, ou desenvolva as chapas no Gerador.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
