# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.6** (2026-10-01)

- Limpar / Converter lê Parasolid (.x_t) do SolidWorks e outros CADs: acha a espessura e planifica sozinho chapa plana e chapa dobrada com dobras paralelas (L, U, Z, calha). Montagem vira uma peça por item, já com a quantidade.
- 3D em todas as peças: o botão "Ver em 3D" mostra a peça com a espessura (DXF, DWG, PDF) ou o modelo 3D dobrado (Parasolid). Arraste para girar.
- Da versão 8.5: preço manual da dobra no orçamento.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
