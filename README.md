# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.39** (2026-11-03)

- Limpar · peça maior que a mesa do laser: novo botão Dividir para caber na mesa. O DXCORE divide a peça em partes para soldar depois e escolhe sozinho onde cortar pelo reaproveitamento: a sobra maior numa chapa só (retalho bom), de preferência sobre uma linha de marcação (a solda cai na caverna) e sem passar por furo. Mostra as partes, a solda da emenda, as chapas e a sobra de cada uma; as partes entram na lista com o material, a espessura e a quantidade da peça inteira.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
