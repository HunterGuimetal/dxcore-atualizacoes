# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.14** (2026-10-05)

- Orçamento: escolha do serviço cobrado: Corte e dobra, Só corte ou Só dobra (peças já cortadas pelo cliente).
- Computador com o atalho antigo (de antes da 7.8) mostra um aviso para baixar e rodar o instalador uma vez. É isso que faz a pasta de dados ficar fixa, sem pedir autorização.
- Pasta de dados definida como padrão no computador: o atalho abre o DXCORE por um servidor local e o navegador não pede mais autorização da pasta. Na primeira vez, escolha a DXCORE-dados da rede uma única vez.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
