# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.97** (2026-11-06)

- Chapas em 2D · o encaixe automático agora também tenta empurrar as peças para o começo da chapa e as encaixa pelos cantos do desenho. Uma peça entra no vão da outra, desencontrada, como se faz à mão. Exemplo: a cruz da caixa-bandeja passa de 3 para 4 por chapa (7 peças: de 3 para 2 chapas).
- Chapas em 2D · com o mesmo número de chapas, fica o encaixe que deixa o maior retalho inteiro na última. Com poucas peças repetidas, elas vão juntas no canto em vez de enfileiradas pela chapa toda.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
