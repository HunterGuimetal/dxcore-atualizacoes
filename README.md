# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.31** (2026-10-28)

- Limpar · PDF com as cotas desenhadas em traço (AutoCAD impresso pelo "Microsoft Print to PDF"): o DXCORE agora lê os números das cotas pela forma dos traços. Com isso acha a escala sozinho (ex.: 1:5) e o tamanho da peça sai certo, conferido com as cotas.
- PDF impresso "ajustado à página" (um pouco fora de escala): o tamanho é acertado pela cota maior da peça (1130 fica 1130, não 1132).
- Folha com várias peças: cada peça pega o nome (ex.: MODELO 1) e a quantidade (ex.: 40 PEÇAS) dos textos ao lado dela, mesmo quando estão em textos separados.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
