# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.28** (2026-10-07)

- Gerador/Editor de peças: o Salvar pergunta onde guardar. Peça de cliente: o DXF e o desenho em PDF vão para a pasta do projeto do cliente. Modelo na biblioteca: a peça entra na Biblioteca de peças. Ou só salvar o projeto.
- Na pasta do cliente e na biblioteca aparece o botão para abrir a peça de volta no Gerador/Editor e continuar mexendo. Salvar de novo atualiza os arquivos, sem duplicar.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
