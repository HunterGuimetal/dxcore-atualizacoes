# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.17** (2026-10-05)

- Ordem de serviço: novo botão "Link do cliente". Cria um link para o cliente acompanhar a produção pelo celular (recebido, corte, dobra, qualidade, pronto, entregue), com as datas e sem preços.
- O link se atualiza sozinho toda vez que a OS muda de etapa (na OS ou no Quadro de produção). Sem internet na hora, o DXCORE manda depois.
- O link pode ser mandado direto no WhatsApp do cliente e pode ser desligado a qualquer momento.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
