# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **7.9** (2026-10-01)

- Senhas dos setores agora fixas e iguais em todos os computadores (a gerência passa as novas para cada setor). Acabou o "às vezes entra, às vezes não".
- Tubo em STEP agora aparece em 3D no Limpar: arraste para girar, roda do mouse para zoom, duplo clique para centralizar. O botão "Ver planificado" mostra a parede aberta.
- Chapas em 2D: dá para arrastar as peças com o mouse e girar 90° (tecla R ou duplo clique). A posição fica guardada no orçamento; "Voltar ao automático" desfaz.
- Leitor de PDF mais esperto, ícone do DXCORE e lançador que se atualiza sozinho (da versão 7.8.1).

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
