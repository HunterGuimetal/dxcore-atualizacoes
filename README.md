Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.

- Gerador de peças: novo "Cortar dobrada" (embaixo, ao lado de Simular dobra). Corte a peça já dobrada com plano em qualquer posição e ângulo, janela/rasgo retangular, furo redondo ou oblongo, numa parede ou atravessando tudo.
