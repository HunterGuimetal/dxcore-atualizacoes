# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.55** (2026-11-06)

- Projetista · arraste para a tela (ou use Importar peças) as peças que você já tem: DXF, DWG, STEP, IGES, Parasolid ou PDF, uma ou várias de uma vez. Chapas entram com o contorno e os furos de verdade; tubos de STEP/IGES entram como tubo.
- Projetista · montar clicando e arrastando: clique na peça e arraste; passando por cima de outra ela assenta em cima, e encosta sozinha nas faces vizinhas. Barra da peça: Altura, Girar (R), Tombar (T), Assentar, Duplicar (Ctrl+D), Tirar (Delete) e Ctrl+Z para desfazer.
- Projetista · Etapas: mostra o serviço montando (ou desmontando) passo a passo, com o que fazer em cada etapa, tocar/pausar e avançar/voltar.
- Projetista · tela mais limpa: os modelos ficam na aba Protótipos, as medidas na aba Medidas, as entregas no menu Entregas e a conversa pode ser recolhida.
- Projetista · prancha desenhada em canvas, fluida a 60 fps; botão Orçar visível no tema claro.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
