# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.60** (2026-11-06)

- Projetista · voz: botão 🔊 no topo da conversa liga a fala; as respostas são faladas com a voz em português do próprio Windows (sem internet), com milímetros, quilos e reais ditos por extenso.
- Projetista · microfone 🎙 ao lado da caixa de texto: clique e fale o comando (“sobe o tampo 30”, “revisa o projeto”). O reconhecimento é do navegador (Edge ou Chrome) e precisa de internet.
- Projetista · mãos livres 🎧: fica ouvindo e responde quando você chama “Jarvis, …” ou “Projetista, …”. Orbe de áudio animada enquanto fala (azul) ou ouve (laranja).

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
