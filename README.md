Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.20** (2026-10-06)

- Encaixe: peça dentro de peça. As peças menores do pedido são cortadas dentro do vazado (janela quadrada, redonda, oblonga…) das peças maiores, com o espaçamento entre peças em volta. Vale também quando a peça maior é girada na chapa, e sai certo no DXF da chapa.
- O orçamento mostra quantas peças foram para dentro de outras e não cobra de novo o aço delas (ele já está no retângulo da peça maior). A gerência pode mudar isso em Parâmetros e preços.
