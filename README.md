# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.25** (2026-10-27)

- Orçamento · nova opção Material do cliente em cada peça (chapa ou tubo): o material daquela peça não é cobrado, as chapas do cliente são encaixadas à parte e não saem do estoque. A proposta mostra "(do cliente)" na peça e a OS avisa quais peças usam o material do cliente. A opção do orçamento todo continua igual.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
