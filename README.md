# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **9.98** (2026-11-06)

- Projetista · projeto pronto (STEP): o projeto de exemplo que fica escondido atrás não aparece mais no mouse. Antes ele mostrava etiquetas e a barra Mover/Tirar de peças invisíveis.
- Projetista · Desmontar tudo agora tira peça por peça da montagem e as deixa deitadas no chão, em fileiras: chapas, perfis, tubos e barras. Cada uma ganha um número em cima, o mesmo da lista. Parede e piso saem da frente e Montar tudo devolve tudo ao lugar.
- Projetista · na ficha de cada peça: Baixar DXF (planificada com furos e linhas de dobra, para chapas e perfis) e Baixar STEP (só aquela peça, para tubos, cantoneiras, perfis U e qualquer outra).

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
