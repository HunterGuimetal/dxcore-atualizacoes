# DXCORE · atualizações

Arquivos que os computadores com o DXCORE instalado baixam para se atualizar.
Versão atual: **10.11** (2026-11-06)

- Rufo capa de muro: a ponta que entra sob o chapéu de pilar sai sem abas e sem pingadeira (recorte de 40 mm até a linha do beiral). Peças A/B: uma ponta; opção para nenhuma ou as duas.
- Gerador · Chapéu de pilar: campo novo Muro entra, com três opções. Dos dois lados é o pilar do meio do muro, com recorte nas duas pontas. De um lado só é o pilar da ponta: recorte do lado do muro e o outro lado fechado com o oitão inteiro. Pilar solto é fechado nos quatro lados.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
