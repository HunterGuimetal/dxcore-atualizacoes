Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.14.1** (2026-10-05)

- Correção: a proposta em PDF (e a OS gerada do orçamento) agora mostram "Somente dobra" ou "Corte a laser (sem dobra)" conforme o serviço escolhido.
- Orçamento: escolha do serviço cobrado: Corte e dobra, Só corte ou Só dobra (peças já cortadas pelo cliente).

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
