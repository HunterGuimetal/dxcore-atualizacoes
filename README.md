# DXCORE by GUIMETAL · atualizações

Arquivos que os computadores da GUIMETAL baixam para atualizar o DXCORE.
Versão atual: **8.40** (2026-10-08)

- Clientes: novo botão Importar planilha. Traz os clientes exportados do GreenApp (ou de qualquer Excel/CSV) de uma vez: o DXCORE liga as colunas sozinho, confere cada CNPJ/CPF, não duplica quem já está cadastrado (só completa o que está em branco) e mostra quem ficou de fora e por quê, com a lista para corrigir. Dá para desfazer a importação no final.
- Endereço, CEP e inscrição estadual vão para as observações do cliente, e o código do cliente no ERP fica guardado na ficha.

O arquivo do programa é cifrado e a atualização é assinada. Não edite estes arquivos à mão.
